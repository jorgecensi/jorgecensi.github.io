GIF Grab

Save GIFs from X (Twitter) posts

How it works

X stores every GIF as a short silent MP4 video. Save MP4 gives you that file as it is: the best quality and the smallest size, and it plays everywhere, including WhatsApp and your camera roll.

Make .gif converts it into a real animated GIF on your device, for places that only take GIFs. Smaller size and fewer frames per second make a lighter file.

On Android, install this app, then use Share on a post in the X app and pick GIF Grab.

To find the post, the link is looked up through the public FxTwitter API (or vxTwitter if that fails); nothing else leaves your device.
