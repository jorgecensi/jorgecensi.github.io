GIF Grab

Save GIFs from X (Twitter) posts

How it works

X stores every GIF as a short silent MP4 video, so that’s the file you save: full quality, small, and it loops in most apps.

X’s servers don’t let other websites download their files directly, so GIF Grab finds the video and hands you its link; your browser saves it. Each card shows the steps for your device.

On Android, install this app, then use Share on a post in the X app and pick GIF Grab.

To find the post, the link is looked up through the public FxTwitter API (or vxTwitter if that fails); nothing else leaves your device.
